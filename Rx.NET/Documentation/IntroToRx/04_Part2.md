# 第 2 部分 - 從事件到見解 

我們生活在一個以驚人速度建立、儲存和分發資料的時代。取用這些資料可能會讓人不知所措，就像試圖直接從消防水栓喝水一樣。我們需要有能力識別重要資料，這意味著我們需要確定哪些相關以及哪些不相關的方法。我們需要獲取資料群組並對其進行集體處理，以發現從任何個別原始輸入中可能不明顯的模式或其他資訊。使用者、客戶和經理需要處理比以往更多的資料，同時仍提供更高的效能和更有用的輸出。

Rx 提供了一些強大的機制，用於從原始資料串流中提取有意義的見解。這首先是將資訊表示為 `IObservable<T>` 串流的主要原因之一。前一章展示了如何建立可觀察序列，因此現在我們將了解如何使用可處理和轉換可觀察序列的各種 Rx 方法來利用已解鎖的強大功能。

Rx 支援大多數標準 LINQ 運算子。它還定義了許多額外的運算子。這些大致分為以下幾類，隨後的每一章都涉及一個類別：

* [篩選](05_Filtering.md)
* [轉換](06_Transformation.md)
* [聚合](07_Aggregation.md)
* [分割](08_Partitioning.md)
* [組合](09_CombiningSequences.md)
