# 第 3 部分 - 務實應用。

本書的第一部分重點介紹了 Rx 的基本概念和型別。在第二部分中，我展示了 Rx 提供的運算子，使我們能夠定義要套用於來源資料的轉換和計算。這第二部分本質上是函數式程式設計。Rx 的運算子大多像數學函式一樣，對於特定的輸入總是表現出相同的方式。它們不受周圍世界狀態的影響，也不會改變其狀態。在函數式程式設計中，此類機制有時被描述為*純粹*（pure）。

這種*純粹性*可以幫助我們了解我們的程式碼將做什麼。這意味著我們不需要了解程式其餘部分的狀態即可了解某個特定部分如何運作。然而，完全脫離外部世界的程式碼不太可能實現任何有用的功能。在實務上，我們需要將這些純粹的計算與更務實的考量聯繫起來。[建立可觀察序列章節](03_CreatingObservableSequences.md)已經展示了如何定義可觀察串流，因此我們已經研究了如何將現實世界的輸入連接到 Rx 的世界中。但是另一端呢？我們如何對處理結果進行有用的操作？

在某些情況下，在 `IObserver` 實作內部執行工作，或使用您已經看到的回呼式訂閱機制可能就足夠了。然而，某些情況需要更複雜的方法。因此，在本書的第三部分中，我們將探討 Rx 提供的一些功能，以幫助將我們在第 2 部分中探討的那種程序與外部世界聯繫起來。
